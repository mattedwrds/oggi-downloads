# Oggi

Keep your next move in sight.

A lightweight floating task panel for Mac. Choose what matters, focus on one thing, and enjoy getting it done.

[Download for Mac](https://github.com/mattedwrds/oggi-downloads/releases/download/v0.3.7/Oggi-0.3.7-macOS.zip)

Requires macOS 14 or later. Supports Apple silicon and Intel Macs.

## Install

Download the ZIP, open it, then drag Oggi to Applications. Quit any older copy before opening the new version.

This trial is not Apple Developer ID signed or notarised. macOS may prevent it from opening. Keep your Mac’s security protections enabled; if it is blocked, wait for a signed release rather than changing those protections.
